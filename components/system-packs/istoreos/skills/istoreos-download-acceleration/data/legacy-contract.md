# Native download compatibility interfaces

`dispatch.sh url ... URL` performs the selected file transfer, default direct and no automatic service start. KSGET_MODE explicitly selects routing. `git-clone HTTPS_URL [DIRECTORY]` maps a public repository through the existing local gateway and invokes native Git. This does not cover every Git dependency, submodule, private repository or forge.

`KAI_DOCKER_ENDPOINT=... dispatch.sh docker-pull IMAGE` selects the exact engine and original image. It does not install/configure an accelerator, inspect/choose a disk or start services. `pip|npm|go RESOLVED_VERSION -- TOOL_ARGS...` executes one existing runtime adapter with literal arguments; installation and persistent SDK selection are separate.

`smoke.sh TOOL VERSION NEW_DIRECTORY` is an explicit isolated acceptance transaction for its documented fixture dependencies; it writes only its selected new directory and declares any existing-service startup in its authorization. It is not a prerequisite for ordinary installation. `evidence.sh` validates matching client/gateway evidence; successful download and acceleration are different outcomes. See dependencies.md for the fixed native fixture recipe and fields, not an Agent task workflow.

Original TLS, checksum, signatures, lock integrity and Go sumdb are retained. No global curl/wget, Git, npmrc, pip or go env rewrite. No forwarding private credentials to alias hosts. Missing components, inactive integration, native errors and partial gateway validation remain explicit facts. The model decides diagnosis, remediation and any retry.
