# iStoreOS capabilities

Discovery only. The model selects tools, skills or none and decides completion. No prerequisites, primary skill or gates. Load skills for full contracts.

| Capability | Scope |
| --- | --- |
| `kai-dev-environment` | Selected SDK/uv operations. |
| `kai-download-acceleration` | Scoped download checks. |
| `kai-project-dependencies` | Project dependencies and sources. |
| `kai-project-run` | Selected project transaction. |
| `kai-software` | Source-bound software operations. |
| `kai-storage-files` | Scoped storage and file facts. |
| `kai-system-information` | OS, package tools and containers. |
| `kai-tool-bootstrap` | Target tool preparation. |
| `istoreos-app-diagnostics` | iStore logs and package facts. |
| `istoreos-app-search` | iStore application candidates. |
| `istoreos-backup-restore` | Selected ChangeGuard operation. |
| `istoreos-docker-acceleration-istoreenhance` | Selected accelerator service. |
| `istoreos-docker-basics` | Docker config and runtime facts. |
| `istoreos-docker-data-root-migrate` | Copy a stopped Docker dataset. |
| `istoreos-download-acceleration` | Alias: kai-download-acceleration. |
| `istoreos-kspeeder-domainfold-fetch` | Selected KSpeeder URL request. |
| `istoreos-logs-and-diagnostics` | Scoped device observations. |
| `istoreos-luci-recovery` | LuCI facts and bounded repair. |
| `istoreos-mise-runtime` | Alias: kai-dev-environment. |
| `istoreos-network-quality` | Alias: kai-network-quality. |
| `istoreos-package-manager` | Alias: kai-software. |
| `istoreos-quickstart-api` | Selected QuickStart API request. |
| `istoreos-run-executable` | Inspect, fetch or run one file. |
| `istoreos-service-manager` | Service facts and one operation. |
| `istoreos-source-introspect` | Startup/config/ownership evidence. |
| `istoreos-storage-path` | Alias: kai-storage-files. |
| `istoreos-system-task-router` | Scoped device facts; legacy ID. |
| `istoreos-systools` | Selected native systools action. |
| `kai-network-quality` | Bounded FastNet observations. |
