## 找到并修正的工程问题

QA 适配器原来只有指定文件时才转发 `length`，因此选择 config 等段落并请求更长窗口时，脚本仍使用默认长度。现已修复，并在实际命令参数边界完成先失败后通过的回归。服务查询可显式请求 `--json-values true`，为完整且已脱敏的 JSON 对象/数组附上解析值，同时保留带来源的原始文本。默认输出不变；不完整窗口、无解析器、错误 JSON 和结果超限均明确报告，不安装依赖、不输出诊断。

此前三个评测条件使用自定义字节读取器，不能代表生产通用读取器的行为。现在三者共用真实 `read_file`，保留原生行窗口、读取快照和裁剪提示；旧字节读取器仅作为显式诊断条件。所有条件仍受同一声明文件白名单约束，不暴露 shell、写入器、凭据或网络。历史结果保留原限定，不回写为新版本通过。
