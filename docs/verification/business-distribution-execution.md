首次自检：清单生成器解析多行标题时抛出 IndexError，无产物成功结论。优化 1：限制标题匹配在单行内，重新运行生成与完整性断言通过；补充 iStoreOS 的相邻路径及文档调用追踪，不能只统计 `kai-*` 引用。未使用优化 2/3。

依赖审阅结论：六个通用入口有五个直接引用 bootstrap，项目依赖和存储 CLI 另引用开发环境。iStoreOS 诊断引用应用搜索，任务观察引用历史 package helper，QuickStart 和下载部分路径引用 Transport 或历史下载资源。BM2 必须封装这些执行资源；路由器对其他业务的推荐仅为可选关联，不能变成所有业务的全量依赖。

测试目标可达性只读探测通过：Linux Docker data-root 位于既有迁移目录；macOS 是 arm64；Windows `kspeeder` 服务返回 Running。未创建容器、部署客户端、改动服务或用户配置。完整基线日志在仓库外本次证据目录；私有配置不写入公开记录。
